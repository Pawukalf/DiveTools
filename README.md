# DiveTools

DiveTools is a collection of practical diving utilities for Garmin Descent dive computers.

Built by a diver for divers, DiveTools provides quick access to commonly used calculations and planning tools directly on your wrist, eliminating the need to carry separate tables, calculators, or mobile apps.

## Features

Current tools include:

- Gas density calculator
- MOD (Maximum Operating Depth) calculator
- END (Equivalent Narcotic Depth) calculator
- SAC/RMV calculations
- Dive planning utilities
- Technical diving reference tools

Additional tools and calculations are added as the project evolves.

## Why DiveTools?

During dive planning, instructors, divemasters, technical divers, and students often need fast access to calculations and safety checks.

DiveTools brings these functions directly to compatible Garmin Descent watches, allowing calculations to be performed anywhere, even without a phone or internet connection.

## Requirements

- Garmin Descent dive computer
- Connect IQ compatible device

## Disclaimer

DiveTools is intended as an educational and planning aid only.

All calculations should be independently verified and used in conjunction with proper training, accepted diving practices, and sound judgment. The user remains solely responsible for dive planning and execution.
